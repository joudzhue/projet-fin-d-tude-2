# Diagrammes du rapport G-ROD

Ce dossier contient les sources PlantUML préparées à partir du code audité. Les diagrammes n'ajoutent aucune fonctionnalité au projet.

| Fichier | Figure proposée | Section du rapport |
|---|---|---|
| `01_architecture_globale.puml` | Architecture globale de G-ROD | 3.1 |
| `02_cas_utilisation_global.puml` | Cas d'utilisation global | 2.2 |
| `03_sequence_creation_devis.puml` | Création d'une demande de devis | 3.4.1 |
| `04_sequence_authentification_jwt.puml` | Authentification Admin JWT | 3.3 |
| `05_sequence_traitement_demande.puml` | Traitement administratif d'une demande | 3.4.2 |
| `06_modele_metier_jpa.puml` | Modèle métier issu des entités JPA | 3.2 |
| `07_gantt_mars_aout_2026.puml` | Gantt reconstruit mars-août 2026 | 2.5 |

Le Gantt distingue les périodes appuyées par l'historique Git, disponible à partir du 28 juillet 2026, des périodes antérieures qui nécessitent une confirmation de l'étudiant.

Les exports `.svg` et `.png` ont été générés à partir de ces mêmes sources et contrôlés visuellement. Le SVG sera privilégié dans Word pour conserver la netteté ; le PNG servira de solution de secours.
